# KidneyLab — Ultimate 3D Medical Learning Game

## Run
npm install
npm run dev

## Build
npm run build

## Features
- 3D kidney/body overview with renal arteries and veins
- Nephron focus mode and animated tubular particles
- Complete urine pathway: collecting system → ureter → bladder → urethra
- Six-stage blood-to-urine journey
- Cinematic camera focus presets
- Disease Lab: healthy, stone, infection, simplified CKD visualization
- All Structures collective Anatomy Atlas
- Game Center with XP, levels and quiz scoring
- Procedural Web Audio sound effects; no audio assets required
- OrbitControls for mouse, touch rotation, pinch/scroll zoom
- Responsive mobile layout

This is an educational visualization, not a diagnostic or treatment tool.
